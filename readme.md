# 校内公开课材料工作台

专为中小学教师评高级职称设计的**校内公开课全套材料一键生成与打印** Web 应用。左侧表单一次输入公开课信息，右侧实时按标准 A4 纸张比例渲染全套材料，支持差异化抄写样例智能生成、在线直接编辑、一键 A4 分页打印及 Word（`.doc`）文档导出。

## 核心功能

1. **一次录入，全套表头同步联动**
   - 支持配置学校全称、通知标题简称、教研组别/科目、授课教师、公开课课题、开课日期（自动提取星期几）、时间段与节次、开课地点、落款日期（默认提前 2 天）、研讨地点及听课人数 $N$（可选填听课教师姓名）。
2. **严格 A4 比例公文与表格排版**
   - **公开课开课通知**：二号宋体加粗标题、带下划线抬头与正文动态变量、三号宋体 2 倍行距正文及教务处右对齐落款。
   - **教研活动记录表**：4 列标准 Word 表格，含研讨主题、组别、时间、地点、参加人员签名区、研讨过程记录大框及教研组长签名栏。
   - **听课记录表**：6 列紧凑 Excel 网格风格，含时间、学校、班级、科目、听课人、课题、授课人、`教 学 过 程` 实录区及左侧竖排 `听 课 意 见` 评价区。
3. **差异化抄写样例生成与在线修改**
   - 根据听课教师人数 $N$，自动生成 $N$ 份内容与视角各不相同的听课记录抄写样例（教学设计与重难点突破、学生主体与互动生成、核心素养与学科思维、教学基本功与课堂节奏等）与 1 份完整教研活动记录样例。
   - 支持点击预览区域文字直接修改（`contenteditable`），打印与导出均保留修改结果。
4. **一键 A4 打印与导出 Word（.doc）**
   - 通过 `@media print` 精准控制每张表格独立占满 1 页 A4 纸（`210mm × 297mm`），不跨页、不溢出。
   - 一键导出兼容 Microsoft Word 与 WPS 的 `.doc` 可编辑文档。

## 本地开发运行

```bash
npm install --legacy-peer-deps
npm run dev
```

访问 `http://localhost:3000`。

## Docker 部署（本地与远程）

本项目采用生产级多阶段 Docker 构建方案（`node:22-bookworm-slim` + Next.js `standalone` 输出），依赖按 `package-lock.json` 通过 `npm ci --legacy-peer-deps` 精确安装。

- **本地一键部署（Windows + Docker Desktop）**：双击或运行 `redeploy.bat`
  - 镜像与容器名：`xiaoneigongkaike`
  - 宿主机端口：`7899`（容器端口 `3000`）
  - 访问地址：`http://localhost:7899`
  - 持久化数据目录：`D:\docker\xiaoneigongkaike\data`
- **远程一键部署**：运行 `upload2remote.bat`
  - 本地构建并导出镜像包后，自动上传并部署至远程服务器 `172.29.173.42:7899`

> **依赖锁文件提示**：若删除过 `package-lock.json` 或新增/升级了依赖包，必须先在项目根目录执行以下命令重新生成锁文件，再运行部署脚本：
> ```bash
> npm install --legacy-peer-deps --package-lock-only
> ```
